# E-Commerce Website

A Python Flask-based E-Commerce Shopping Cart Website.

## Project Description

This project is an online shopping website developed using Python, Flask, HTML, CSS, and SQLite.

Users can browse products, search for products, add products to the shopping cart, place orders, manage their profile, add products to wishlist, and submit product reviews.

The website also includes an Admin Panel for managing orders and updating order status.

## Features

- User Registration and Login
- Product Listing
- Product Search
- Category Filtering
- Shopping Cart
- Checkout
- Order Management
- My Orders
- Order Status Tracking
- Wishlist
- Product Reviews and Ratings
- User Profile
- Profile Photo Upload
- Admin Login
- Admin Order Management
- Update Order Status
- SQLite Database

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
